## Что делает программа

Программа:

1. Считывает число `N`.
2. Считывает `N` чисел в массив `tracks`.
3. Если `N > 0`, сортирует массив по возрастанию быстрой сортировкой `QuickSort`.
4. Выводит отсортированный массив через пробел.

Главная идея — **QuickSort** — быстрая сортировка. Это алгоритм «разделяй и властвуй»:

- выбирается опорный элемент `pivot`;
- массив переставляется так, чтобы слева от `pivot` были элементы `<= pivot`, а справа — `> pivot`;
- после этого `pivot` стоит на своём окончательном месте;
- затем рекурсивно сортируются левая и правая части.

## Исходный код

```cpp
#include <iostream>
#include <algorithm>
#include <cstdlib>

int Partrition(int list[], int left, int right){

    int random = left + rand() % (right - left + 1);
    std::swap(list[random], list[right]);
    
    int pivot = list[right];
    int i = left - 1;

    for(int j = left; j <right; j++){
        if (list[j] <= pivot){
            i +=1;
            std::swap(list[i], list[j]);
        }
    }
    std::swap(list[i+1], list[right]);
    return i + 1;
}

void QuickSort(int list[], int left, int right){
    if (left < right){
        int q = Partrition(list, left, right);

        QuickSort(list, left, q-1);
        QuickSort(list, q+1, right);
    }
}


int main(){
    int N;
    std::cin >> N;
    int tracks[N];
    for (int i = 0; i < N; i++){
        std::cin >> tracks[i];
    }

    if (N > 0) {
        QuickSort(tracks, 0, N - 1);
    }

    for (int i = 0; i < N; i++){
        std::cout << tracks[i] << " ";
    }
    return 0;
}
```

## Разбор `main`

```cpp
int main(){
    int N;
    std::cin >> N;
    int tracks[N];
    for (int i = 0; i < N; i++){
        std::cin >> tracks[i];
    }

    if (N > 0) {
        QuickSort(tracks, 0, N - 1);
    }

    for (int i = 0; i < N; i++){
        std::cout << tracks[i] << " ";
    }
    return 0;
}
```

Что происходит:

- `std::cin >> N;` — читаем количество элементов.
- `int tracks[N];` — создаём массив из `N` элементов.
  - **Важно:** в строгом стандарте C++ так нельзя, потому что `N` известен только во время выполнения. Это VLA — variable length array. GCC/Clang часто разрешают это как расширение. Если преподаватель спросит, можно сказать: «В стандартном C++ лучше использовать `std::vector<int> tracks(N);`, но здесь компилятор GCC разрешает VLA».
- Цикл `for` считывает числа в массив.
- `if (N > 0)` — защита, чтобы не вызывать сортировку с `N - 1 = -1`.
- `QuickSort(tracks, 0, N - 1);` — сортируем весь массив от индекса `0` до `N - 1`.
- Последний цикл выводит массив.

Почему передаётся `tracks`, а не `tracks[N]`?  
Потому что имя массива в C++ при передаче в функцию превращается в указатель на первый элемент. То есть функция получает доступ к оригинальному массиву и может его менять.

## Функция `QuickSort`

```cpp
void QuickSort(int list[], int left, int right){
    if (left < right){
        int q = Partrition(list, left, right);

        QuickSort(list, left, q-1);
        QuickSort(list, q+1, right);
    }
}
```

Параметры:

- `list[]` — сортируемый массив;
- `left` — левая граница рассматриваемой части;
- `right` — правая граница.

Условие `if (left < right)` — база рекурсии.

Если `left >= right`, значит в части массива 0 или 1 элемент. Такая часть уже отсортирована, ничего делать не надо.

Если элементов больше одного:

1. Вызывается `Partrition(list, left, right)`.
2. Она возвращает индекс `q`, на котором оказался опорный элемент.
3. После этого:
   - всё слева от `q` меньше или равно `list[q]`;
   - всё справа от `q` больше `list[q]`;
   - сам `list[q]` уже стоит на своём окончательном месте.
4. Рекурсивно сортируем:
   - `QuickSort(list, left, q - 1);` — левую часть;
   - `QuickSort(list, q + 1, right);` — правую часть.

Почему `q - 1` и `q + 1`, а не `q`?  
Потому что элемент `q` уже на своём месте. Его повторно сортировать не нужно.

## Функция `Partrition` (Partition)

```cpp
int Partrition(int list[], int left, int right){

    int random = left + rand() % (right - left + 1);
    std::swap(list[random], list[right]);
    
    int pivot = list[right];
    int i = left - 1;

    for(int j = left; j < right; j++){
        if (list[j] <= pivot){
            i += 1;
            std::swap(list[i], list[j]);
        }
    }
    std::swap(list[i+1], list[right]);
    return i + 1;
}
```

В названии функции опечатка: правильно `Partition`, а не `Partrition`. На работу это не влияет.

### Выбор случайного опорного элемента

```cpp
int random = left + rand() % (right - left + 1);
std::swap(list[random], list[right]);
```

`right - left + 1` — количество элементов на отрезке `[left, right]`.

`rand() % (right - left + 1)` даёт число от `0` до `right - left`.

Прибавляем `left` — получаем случайный индекс в диапазоне от `left` до `right` включительно.

Затем меняем случайный элемент с правым элементом `list[right]`.

Зачем?  
Чтобы опорным стал случайный элемент, а не всегда последний. Это уменьшает вероятность худшего случая, например когда массив уже отсортирован.

После этого опорный элемент лежит в `list[right]`.

### Запоминание опорного значения

```cpp
int pivot = list[right];
```

Здесь `pivot` — это **значение**, а не индекс. Мы запоминаем значение опорного элемента.

Сам элемент пока физически находится в `list[right]`.

### Граница `i`

```cpp
int i = left - 1;
```

`i` — это индекс последнего элемента в левой части, которая содержит элементы `<= pivot`.

Изначально левая часть пустая, поэтому `i = left - 1`.

### Основной цикл

```cpp
for(int j = left; j < right; j++){
    if (list[j] <= pivot){
        i += 1;
        std::swap(list[i], list[j]);
    }
}
```

Идём `j` от `left` до `right - 1`. Элемент `list[right]` не трогаем, потому что там лежит опорный элемент.

Инвариант цикла:

- `list[left..i]` — элементы `<= pivot`;
- `list[i+1..j-1]` — элементы `> pivot`;
- `list[j..right-1]` — ещё не обработанные элементы;
- `list[right]` — опорный элемент.

Если `list[j] <= pivot`:

1. Увеличиваем `i` на 1.
2. Меняем местами `list[i]` и `list[j]`.

Тем самым мы расширяем левую часть и отправляем туда текущий маленький элемент.

Если `list[j] > pivot`, ничего не делаем. Этот элемент и так должен остаться справа.

### Постановка опорного элемента на место

```cpp
std::swap(list[i+1], list[right]);
return i + 1;
```

После цикла:

- `list[left..i]` — элементы `<= pivot`;
- `list[i+1..right-1]` — элементы `> pivot`;
- `list[right]` — опорный элемент.

Индекс `i + 1` — это первое место, где должен стоять опорный элемент. Меняем `list[i+1]` и `list[right]`.

Теперь:

- всё слева от `i+1` меньше или равно `pivot`;
- `list[i+1] == pivot`;
- всё справа больше `pivot`.

Возвращаем `i + 1` — индекс опорного элемента.

## Пример работы

Пусть массив:

```cpp
[5, 3, 8, 1, 2]
```

Для простоты представим, что случайный выбор попал на последний элемент. Тогда `pivot = 2`.

`i = -1`.

Идём `j` от `0` до `3`:

- `j = 0`, `list[0] = 5`, `5 <= 2`? Нет.
- `j = 1`, `list[1] = 3`, `3 <= 2`? Нет.
- `j = 2`, `list[2] = 8`, `8 <= 2`? Нет.
- `j = 3`, `list[3] = 1`, `1 <= 2`? Да.
  - `i = 0`
  - меняем `list[0]` и `list[3]`
  - массив становится `[1, 3, 8, 5, 2]`

После цикла меняем `list[i+1]` и `list[right]`, то есть `list[1]` и `list[4]`:

```cpp
[1, 2, 8, 5, 3]
```

Возвращаем `i + 1 = 1`.

Теперь `2` стоит на своём месте. Слева — `[1]`, справа — `[8, 5, 3]`. Дальше рекурсивно сортируются эти части.

Итог:

```cpp
[1, 2, 3, 5, 8]
```

## Сложность и свойства алгоритма

### Средний случай

В среднем массив делится примерно пополам. Глубина рекурсии — `O(log n)`. На каждом уровне выполняется `O(n)` работы.

Итого: **O(n log n)**.

### Худший случай

Если опорный элемент каждый раз оказывается минимальным или максимальным, деление будет крайне неравномерным: например, слева 0 элементов, справа `n-1`.

Тогда: **O(n²)**.

Случайный выбор опорного элемента уменьшает вероятность такого случая, но не убирает её полностью.

### Память

Дополнительный массив не создаётся, сортировка происходит **на месте**.

Но рекурсия использует стек вызовов:

- в среднем глубина `O(log n)`;
- в худшем — `O(n)`.

### Устойчивость

QuickSort **не является устойчивой** сортировкой. Равные элементы могут поменять относительный порядок. Для чисел это неважно.

## Вопросы на защите

### 1. Что такое опорный элемент?

Это элемент `pivot`, относительно которого массив делится на две части: `<= pivot` и `> pivot`.

### 2. Зачем случайный опорный элемент?

Чтобы уменьшить вероятность худшего случая `O(n²)`, особенно на уже отсортированных или почти отсортированных массивах.

### 3. Почему `rand() % (right - left + 1)`?

Потому что нужно получить индекс от `left` до `right` включительно. Количество элементов: `right - left + 1`.

### 4. Почему `i = left - 1`?

Потому что изначально левая часть, где элементы `<= pivot`, пустая. `i` — граница этой части.

### 5. Почему цикл `j < right`, а не `j <= right`?

Потому что `list[right]` — это опорный элемент. Его не нужно сравнивать с самим собой. Он будет поставлен на место после цикла.

### 6. Почему после цикла `swap(list[i+1], list[right])`?

Потому что `i + 1` — это первая позиция после всех элементов `<= pivot`. Именно туда нужно поставить `pivot`.

### 7. Почему рекурсивные вызовы `q-1` и `q+1`?

Потому что `q` — индекс опорного элемента. Он уже на своём окончательном месте. Его сортировать не нужно.

### 8. Что если `N = 0`?

В коде есть `if (N > 0)`, поэтому сортировка не вызовется. Но `int tracks[N]` при `N = 0` — нестандартная ситуация. В обычном C++ лучше использовать `std::vector`.

### 9. Что если `N = 1`?

`QuickSort(tracks, 0, 0)` не сделает ничего, потому что `left < right` ложно. Массив уже отсортирован.

### 10. Что если все элементы равны?

В этой реализации все равные элементы уйдут в левую часть, и разбиение будет очень неравномерным. Это может дать `O(n²)`. Чтобы избежать этого, используют трёхпутевое разбиение, но в этом коде его нет.

### 11. Что делает `std::swap`?

Меняет два значения местами. Подключён через `<algorithm>`.

### 12. Зачем `#include <cstdlib>`?

Для функции `rand()`. Она объявлена в `<cstdlib>`.

### 13. Почему нет `srand(time(nullptr))`?

Потому что для корректности сортировки это не нужно. Без `srand` последовательность `rand()` будет одинаковой при каждом запуске, но алгоритм всё равно работает правильно. Если нужно настоящее разнообразие, можно добавить `srand(time(nullptr));` в начало `main`.

### 14. Что нестандартного в коде?

`int tracks[N];` — это VLA. В стандартном C++ размер массива должен быть константой времени компиляции. Здесь используется расширение компилятора. Альтернатива — `std::vector<int> tracks(N);`.

## Краткое резюме

«Программа реализует быструю сортировку. Функция `QuickSort` рекурсивно сортирует массив. Она вызывает `Partition`, которая выбирает случайный опорный элемент, переносит его в конец, затем переставляет элементы так, чтобы слева были элементы меньше или равные опорному, а справа — больше. После этого опорный элемент оказывается на своём окончательном месте. Затем `QuickSort` рекурсивно сортирует левую и правую части. В среднем сложность `O(n log n)`, в худшем `O(n²)`. Сортировка происходит на месте, но использует стек рекурсии. Алгоритм неустойчивый».
