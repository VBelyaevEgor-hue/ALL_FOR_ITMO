## Что делает программа

Программа:

1. Считывает три числа: `n`, `a`, `b`.
2. Генерирует массив `arr` из `n` псевдослучайных 32-битных чисел.
3. Находит **медиану** этого массива с помощью алгоритма `quickSelect` (быстрый выбор).
4. Вычисляет сумму абсолютных отклонений всех элементов от медианы:
   \[
   \sum_{i=0}^{n-1} |arr[i] - x|,
   \]
   где `x` — найденная медиана.
5. Выводит полученную сумму.

Иными словами, программа ищет точку на числовой прямой, для которой сумма расстояний до всех элементов массива минимальна. Такой точкой является медиана.

## Исходный код

```cpp
#include <iostream>
#include <vector>
#include <cstdint>
#include <cstdlib>
using namespace std;

uint32_t cur = 0;

uint32_t nextRand24(uint32_t a, uint32_t b) {
    cur = cur * a + b;
    return cur >> 8;
}

uint32_t nextRand32(uint32_t a, uint32_t b) {
    uint32_t x = nextRand24(a, b);
    uint32_t y = nextRand24(a, b);
    return (x << 8) ^ y;
}

// k-й по порядку элемент (нумерация с 0), массив меняется на месте
uint32_t quickSelect(vector<uint32_t>& arr, int k) {
    int l = 0, r = (int)arr.size() - 1;
    while (l < r) {
        uint32_t pivot = arr[l + rand() % (r - l + 1)];

        int lt = l, i = l, gt = r;
        while (i <= gt) {
            if (arr[i] < pivot) {
                uint32_t t = arr[lt]; arr[lt] = arr[i]; arr[i] = t;
                lt++; i++;
            } else if (arr[i] > pivot) {
                uint32_t t = arr[gt]; arr[gt] = arr[i]; arr[i] = t;
                gt--;
            } else {
                i++;
            }
        }
        // [l, lt-1] < pivot, [lt, gt] == pivot, [gt+1, r] > pivot
        if (k < lt)      r = lt - 1;
        else if (k > gt) l = gt + 1;
        else             return pivot;
    }
    return arr[k];
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    uint32_t n, a, b;
    cin >> n >> a >> b;

    vector<uint32_t> arr(n);
    for (uint32_t i = 0; i < n; i++)
        arr[i] = nextRand32(a, b);

    long long x = quickSelect(arr, n / 2);   // медиана

    long long sum_ans = 0;
    for (uint32_t i = 0; i < n; i++) {
        long long d = (long long)arr[i] - x;
        sum_ans += d < 0 ? -d : d;
    }

    cout << sum_ans << "\n";
}
```

## Разбор `main`

```cpp
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    uint32_t n, a, b;
    cin >> n >> a >> b;

    vector<uint32_t> arr(n);
    for (uint32_t i = 0; i < n; i++)
        arr[i] = nextRand32(a, b);

    long long x = quickSelect(arr, n / 2);   // медиана

    long long sum_ans = 0;
    for (uint32_t i = 0; i < n; i++) {
        long long d = (long long)arr[i] - x;
        sum_ans += d < 0 ? -d : d;
    }

    cout << sum_ans << "\n";
}
```

Что происходит:

- `ios::sync_with_stdio(false); cin.tie(nullptr);` — ускоряют ввод-вывод.
- Считываются `n`, `a`, `b`. `n` — количество элементов, `a` и `b` — параметры генератора.
- Создаётся вектор `arr` размера `n`.
- Цикл заполняет массив значениями `nextRand32(a, b)`.
- `quickSelect(arr, n / 2)` находит элемент с индексом `n / 2` в отсортированном порядке (нумерация с нуля). Это медиана (для чётного `n` — верхняя медиана, но для суммы абсолютных отклонений подходит любая точка между двумя средними).
- Затем вычисляется сумма абсолютных отклонений:
  - `long long d = (long long)arr[i] - x;` — разность приводится к 64-битному знаковому типу, чтобы избежать переполнения.
  - `sum_ans += d < 0 ? -d : d;` — добавляется модуль разности.
- Выводится `sum_ans`.

**Важно:** `quickSelect` переставляет элементы массива. Но сумма абсолютных отклонений зависит только от множества значений, а не от их порядка. Поэтому то, что массив после `quickSelect` не отсортирован и перемешан, не влияет на правильность суммы.

### Типы данных

- `uint32_t` — беззнаковое 32-битное целое (0 … 4 294 967 295). Используется для элементов массива и параметров генератора.
- `long long` — знаковое 64-битное целое. Используется для медианы `x` и суммы `sum_ans`, потому что сумма может достигать `n * 2^32`, что не влезает в 32 бита.

## Генераторы `nextRand24` и `nextRand32`

```cpp
uint32_t cur = 0;

uint32_t nextRand24(uint32_t a, uint32_t b) {
    cur = cur * a + b;
    return cur >> 8;
}

uint32_t nextRand32(uint32_t a, uint32_t b) {
    uint32_t x = nextRand24(a, b);
    uint32_t y = nextRand24(a, b);
    return (x << 8) ^ y;
}
```

### `nextRand24`

Это линейный конгруэнтный генератор (LCG):

- Глобальная переменная `cur` изначально равна 0.
- При каждом вызове: `cur = cur * a + b`.
- Возвращается `cur >> 8` — старшие 24 бита (сдвиг вправо на 8 отбрасывает младшие 8 бит).
- Результат — число от 0 до \(2^{24} - 1 = 16\,777\,215\).

### `nextRand32`

Он собирает 32-битное число из двух 24-битных:

- `x = nextRand24(a, b)` — первое 24-битное число.
- `y = nextRand24(a, b)` — второе 24-битное число.
- `(x << 8) ^ y` — сдвигаем `x` на 8 бит влево и складываем по XOR с `y`.

Как это работает по битам:

- `x` занимает биты 0…23. После `x << 8` он занимает биты 8…31.
- `y` занимает биты 0…23.
- XOR накладывает `y` на младшие 24 бита результата.
- Итог: младшие 8 бит — от `y`, следующие 16 бит — XOR от `x` и `y`, старшие 8 бит — от `x`.
- Получается псевдослучайное 32-битное число.

Генератор детерминированный: при одних и тех же `a`, `b` и начальном `cur = 0` последовательность чисел будет одинаковой.

## Функция `quickSelect`

```cpp
uint32_t quickSelect(vector<uint32_t>& arr, int k) {
    int l = 0, r = (int)arr.size() - 1;
    while (l < r) {
        uint32_t pivot = arr[l + rand() % (r - l + 1)];

        int lt = l, i = l, gt = r;
        while (i <= gt) {
            if (arr[i] < pivot) {
                uint32_t t = arr[lt]; arr[lt] = arr[i]; arr[i] = t;
                lt++; i++;
            } else if (arr[i] > pivot) {
                uint32_t t = arr[gt]; arr[gt] = arr[i]; arr[i] = t;
                gt--;
            } else {
                i++;
            }
        }
        if (k < lt)      r = lt - 1;
        else if (k > gt) l = gt + 1;
        else             return pivot;
    }
    return arr[k];
}
```

Функция находит `k`-й по порядку элемент (нумерация с 0), то есть элемент, который стоял бы на позиции `k`, если бы массив отсортировали. Массив при этом изменяется на месте.

### Параметры

- `arr` — ссылка на вектор чисел.
- `k` — индекс искомого элемента в отсортированном порядке (0 ≤ k < n).

### Инициализация

```cpp
int l = 0, r = (int)arr.size() - 1;
```

- `l` — левая граница текущего рассматриваемого отрезка.
- `r` — правая граница.
- Пока `l < r`, продолжаем поиск.

### Выбор опорного элемента

```cpp
uint32_t pivot = arr[l + rand() % (r - l + 1)];
```

- Выбирается случайный индекс от `l` до `r` включительно.
- Значение по этому индексу становится опорным `pivot`.

Случайный выбор уменьшает вероятность худшего случая \(O(n^2)\).

### Трёхпутевое разбиение

```cpp
int lt = l, i = l, gt = r;
while (i <= gt) {
    if (arr[i] < pivot) {
        swap(arr[lt], arr[i]);
        lt++; i++;
    } else if (arr[i] > pivot) {
        swap(arr[gt], arr[i]);
        gt--;
    } else {
        i++;
    }
}
```

Это алгоритм **трёхпутевого разбиения** (Dutch national flag). Он делит отрезок `[l, r]` на три части:

- `[l, lt-1]` — элементы **меньше** `pivot`;
- `[lt, gt]` — элементы **равные** `pivot`;
- `[gt+1, r]` — элементы **больше** `pivot`.

Переменные:

- `lt` — граница «меньше» (less than). Изначально `lt = l`.
- `i` — текущий просматриваемый элемент. Изначально `i = l`.
- `gt` — граница «больше» (greater than). Изначально `gt = r`.

Цикл работает, пока `i <= gt`.

Разбор случаев:

1. `arr[i] < pivot`:
   - Меняем `arr[lt]` и `arr[i]`.
   - Увеличиваем `lt` и `i`.
   - Элемент отправляется в левую часть.

2. `arr[i] > pivot`:
   - Меняем `arr[gt]` и `arr[i]`.
   - Уменьшаем `gt`, но **не** увеличиваем `i`.
   - Потому что на место `i` пришёл элемент из правой части, который ещё не просмотрен.
   - Элемент отправляется в правую часть.

3. `arr[i] == pivot`:
   - Просто увеличиваем `i`.
   - Элемент остаётся в средней части.

После цикла:

- всё слева от `lt` меньше `pivot`;
- всё от `lt` до `gt` включительно равно `pivot`;
- всё справа от `gt` больше `pivot`.

### Сужение диапазона поиска

```cpp
if (k < lt)      r = lt - 1;
else if (k > gt) l = gt + 1;
else             return pivot;
```

- Если искомый индекс `k` меньше `lt`, значит, он в левой части. Ищем там: `r = lt - 1`.
- Если `k` больше `gt`, значит, он в правой части. Ищем там: `l = gt + 1`.
- Иначе `k` попадает в среднюю часть, где все элементы равны `pivot`. Значит, искомый элемент — это `pivot`. Возвращаем его.

Если цикл `while (l < r)` завершился, значит, остался один элемент. Возвращаем `arr[k]` (или `arr[l]`, что то же самое).

### Почему это работает

После каждого разбиения мы точно знаем, в какой части находится искомый элемент. Отбрасываем остальные части. В среднем размер рассматриваемой части уменьшается примерно вдвое, поэтому алгоритм работает за \(O(n)\) в среднем.

## Как работает трёхпутевое разбиение

Рассмотрим массив `[5, 3, 8, 1, 2]`, ищем медиану `k = 2`.

Пусть случайно выбран `pivot = 3`.

Начало: `l = 0, r = 4, lt = 0, i = 0, gt = 4`.

- `i = 0`, `arr[0] = 5 > 3`: меняем `arr[0]` и `arr[4]` → `[2, 3, 8, 1, 5]`, `gt = 3`.
- `i = 0`, `arr[0] = 2 < 3`: меняем `arr[0]` и `arr[0]` (ничего), `lt = 1, i = 1`.
- `i = 1`, `arr[1] = 3 == 3`: `i = 2`.
- `i = 2`, `arr[2] = 8 > 3`: меняем `arr[2]` и `arr[3]` → `[2, 3, 1, 8, 5]`, `gt = 2`.
- `i = 2`, `arr[2] = 1 < 3`: меняем `arr[2]` и `arr[1]` → `[2, 1, 3, 8, 5]`, `lt = 2, i = 3`.
- Теперь `i = 3 > gt = 2`, цикл закончен.

Итог: `[2, 1, 3, 8, 5]`.

- `[l, lt-1] = [0, 1]` — `[2, 1]` < 3.
- `[lt, gt] = [2, 2]` — `[3]` == 3.
- `[gt+1, r] = [3, 4]` — `[8, 5]` > 3.

`k = 2`. Проверяем: `k < lt`? `2 < 2` — нет. `k > gt`? `2 > 2` — нет. Значит, `k` в средней части. Возвращаем `pivot = 3`.

Медиана равна 3.

## Почему сумма абсолютных отклонений минимальна на медиане

Для набора чисел \(a_1, a_2, \dots, a_n\) функция

\[
f(x) = \sum_{i=1}^{n} |a_i - x|
\]

достигает минимума в точке, которая является **медианой** этого набора.

Интуиция:

- Если `x` меньше медианы, то справа от `x` больше чисел, чем слева. При увеличении `x` на единицу сумма расстояний до чисел справа уменьшится на количество этих чисел, а до чисел слева увеличится на количество чисел слева. Так как справа больше, сумма уменьшится.
- Если `x` больше медианы, ситуация обратная: при уменьшении `x` сумма уменьшится.
- Минимум достигается, когда количество чисел слева и справа уравновешено, то есть в медиане.

Если `n` чётное, то любая точка между двумя средними элементами даёт одинаковый минимум. Поэтому выбор `n / 2` (верхняя медиана) корректен.

---

## Пример работы

Пусть `n = 5`, массив после генерации: `[5, 3, 8, 1, 2]`.

`n / 2 = 2`. Ищем 2-й по порядку элемент (нумерация с 0). В отсортированном массиве `[1, 2, 3, 5, 8]` на позиции 2 стоит `3`.

Медиана `x = 3`.

Сумма абсолютных отклонений:

\[
|5-3| + |3-3| + |8-3| + |1-3| + |2-3| = 2 + 0 + 5 + 2 + 1 = 10.
\]

Программа выведет `10`.

## Сложность и свойства алгоритма

### Временная сложность

- Генерация массива: \(O(n)\).
- `quickSelect`: в среднем \(O(n)\), в худшем \(O(n^2)\). Случайный выбор опорного элемента делает худший случай маловероятным.
- Подсчёт суммы: \(O(n)\).

Итоговая средняя сложность: **\(O(n)\)**.

### Память

- Вектор `arr` — \(O(n)\).
- `quickSelect` работает на месте, дополнительная память \(O(1)\).
- Рекурсии нет, поэтому стек не растёт.

### Устойчивость

Алгоритм не является сортировкой, поэтому понятие устойчивости неприменимо. `quickSelect` просто находит k-й элемент.

### Особенности реализации

- `rand()` без `srand()` даёт одну и ту же последовательность при каждом запуске. Для отладки это удобно, для реальной случайности нужно добавить `srand(time(nullptr))`.
- `rand() % (r - l + 1)` может быть неравномерным, если диапазон больше `RAND_MAX`, но для учебной задачи это не критично.
- Если `n = 0`, программа упадёт: `arr.size() - 1` даст `-1`, и `quickSelect` выйдет за границы. Входные данные предполагают `n > 0`.

## Вопросы на защите

### 1. Что такое медиана?

Медиана — это значение, которое делит упорядоченный набор чисел на две равные части. Для нечётного количества — средний элемент. Для чётного — любое число между двумя средними.

### 2. Почему сумма абсолютных отклонений минимальна на медиане?

Потому что при сдвиге от медианы в любую сторону сумма расстояний до большего количества точек увеличивается сильнее, чем уменьшается до меньшего. Формально функция \(f(x) = \sum |a_i - x|\) выпукла и её минимум достигается в медиане.

### 3. Что делает `quickSelect`?

Находит k-й по порядку элемент массива (элемент, который оказался бы на позиции k после сортировки) за среднее время \(O(n)\), не сортируя весь массив.

### 4. Как работает трёхпутевое разбиение?

Делит отрезок на три части: меньше `pivot`, равные `pivot`, больше `pivot`. Используются три указателя: `lt`, `i`, `gt`. Это позволяет эффективно обрабатывать массивы с большим количеством одинаковых элементов.

### 5. Почему при `arr[i] > pivot` мы не увеличиваем `i`?

Потому что после обмена `arr[i]` и `arr[gt]` на место `i` приходит элемент из правой части, который ещё не просмотрен. Его нужно обработать на следующей итерации.

### 6. Почему после разбиения мы возвращаем `pivot`, если `k` попал в среднюю часть?

Потому что все элементы в средней части равны `pivot`. Если `k` находится в этом диапазоне, значит, k-й элемент равен `pivot`.

### 7. Зачем нужен `nextRand32`?

Чтобы получить 32-битные псевдослучайные числа. `nextRand24` даёт только 24 бита, поэтому два вызова объединяются через сдвиг и XOR.

### 8. Почему `sum_ans` имеет тип `long long`?

Потому что сумма абсолютных отклонений может быть очень большой. Например, при `n = 10^6` и разбросе значений до `2^32` сумма может достигать `10^6 * 4*10^9 = 4*10^15`, что не влезает в 32-битное целое.

### 9. Что будет, если `n` чётное?

`n / 2` даст верхнюю медиану. Для суммы абсолютных отклонений это допустимо, так как любая точка между двумя средними элементами даёт одинаковый минимум.

### 10. В чём отличие `quickSelect` от `QuickSort`?

`QuickSort` сортирует весь массив и работает \(O(n \log n)\) в среднем. `QuickSelect` ищет только один элемент и работает \(O(n)\) в среднем, потому что отбрасывает одну из частей после разбиения.

### 11. Что нестандартного в коде?

- `#include <cstdlib>` для `rand()`.
- `using namespace std;` — удобно, но не рекомендуется в больших проектах.
- `rand()` без `srand()` — детерминированная последовательность.
- Нет проверки на `n = 0`.

## Краткое резюме

«Программа генерирует массив из `n` псевдослучайных 32-битных чисел с помощью линейного конгруэнтного генератора. Затем с помощью алгоритма `quickSelect` находит медиану массива. `quickSelect` использует трёхпутевое разбиение: выбирает случайный опорный элемент, делит массив на элементы меньше, равные и больше опорного, и продолжает поиск только в той части, где находится искомый индекс. После нахождения медианы программа вычисляет сумму абсолютных отклонений всех элементов от медианы. Эта сумма минимальна, потому что медиана является точкой минимума функции суммы расстояний. Средняя сложность `O(n)`, память `O(n)` для массива. В коде используются `uint32_t` для элементов и `long long` для суммы».
