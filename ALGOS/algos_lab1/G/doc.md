## Что делает программа

Программа:

1. Считывает число `N`.
2. Считывает `N` чисел в массив `arr1`.
3. Для каждого элемента массива (в исходном порядке) выводит число — сколько **предыдущих** элементов массива не превосходят текущий по значению (то есть `<=`).
4. После вывода обновляет счётчик частот для текущего значения.

Иначе говоря, для каждого `i` программа печатает:

\[
\text{ans}[i] = \#\{ j < i \mid arr1[j] \le arr1[i] \}
\]

Несмотря на название функции `CountingSort`, программа **не сортирует** массив. Она лишь использует идею подсчёта частот (counting), чтобы быстро находить количество уже встреченных чисел, не больших текущего.

---

## Исходный код

```cpp
#include <iostream>
#include <vector>

void CountingSort(int arr1[], int N){
    int counts[101];
    for (int i = 0; i < 101; i++){
        counts[i] = 0;
    }

    for (int i = 0; i < N; i++){
        int sum = 0;
        for (int j = 1; j <= arr1[i]; j++){
            sum += counts[j];
        }
        std::cout << sum << " ";
        counts[arr1[i]] = counts[arr1[i]] + 1;
    }
}

int main(){
    int N;
    std:: cin >> N;

    int arr1[N];
    for (int i = 0; i < N; i++){
        std:: cin >> arr1[i];
    }

    CountingSort(arr1, N);
    return 0;
}
```

## Разбор `main`

```cpp
int main(){
    int N;
    std:: cin >> N;

    int arr1[N];
    for (int i = 0; i < N; i++){
        std:: cin >> arr1[i];
    }

    CountingSort(arr1, N);
    return 0;
}
```

Что происходит:

- `std:: cin >> N;` — читаем количество элементов. Запись `std:: cin` с пробелом допустима: пробелы между `::` и `cin` игнорируются.
- `int arr1[N];` — создаём массив из `N` элементов.
  - **Важно:** это VLA (variable length array). В стандартном C++ размер массива должен быть константой времени компиляции. GCC/Clang разрешают это как расширение. В идеале нужно использовать `std::vector<int> arr1(N);`.
- Цикл считывает `N` чисел в массив.
- `CountingSort(arr1, N);` — вызываем функцию, которая выводит ответ для каждого элемента.
- Функция ничего не возвращает и не меняет массив. Она только печатает результаты.

Почему передаётся `arr1`, а не `arr1[N]`?  
Потому что имя массива при передаче в функцию превращается в указатель на первый элемент. Функция получает доступ к оригинальному массиву.

## Функция `CountingSort`

```cpp
void CountingSort(int arr1[], int N){
    int counts[101];
    for (int i = 0; i < 101; i++){
        counts[i] = 0;
    }

    for (int i = 0; i < N; i++){
        int sum = 0;
        for (int j = 1; j <= arr1[i]; j++){
            sum += counts[j];
        }
        std::cout << sum << " ";
        counts[arr1[i]] = counts[arr1[i]] + 1;
    }
}
```

Параметры:

- `arr1[]` — массив чисел;
- `N` — количество элементов.

### Массив `counts`

```cpp
int counts[101];
for (int i = 0; i < 101; i++){
    counts[i] = 0;
}
```

Создаётся массив `counts` из 101 элемента (индексы 0…100). Все элементы обнуляются.

`counts[x]` будет хранить, сколько раз значение `x` уже встретилось среди **предыдущих** элементов массива.

Почему 101?  
Потому что предполагается, что все входные числа лежат в диапазоне от 1 до 100 включительно. Индекс 0 не используется, но массив всё равно имеет размер 101, чтобы можно было обращаться по индексам 1…100.

### Основной цикл

```cpp
for (int i = 0; i < N; i++){
    int sum = 0;
    for (int j = 1; j <= arr1[i]; j++){
        sum += counts[j];
    }
    std::cout << sum << " ";
    counts[arr1[i]] = counts[arr1[i]] + 1;
}
```

Для каждого элемента `arr1[i]`:

1. `int sum = 0;` — обнуляем счётчик.
2. Внутренний цикл `for (int j = 1; j <= arr1[i]; j++)` суммирует `counts[j]` для всех `j` от 1 до `arr1[i]`.
   - `counts[j]` — сколько раз значение `j` уже встречалось ранее.
   - Сумма этих значений — это количество предыдущих элементов, которые `<= arr1[i]`.
3. `std::cout << sum << " ";` — выводим полученное число.
4. `counts[arr1[i]] = counts[arr1[i]] + 1;` — увеличиваем счётчик для текущего значения. Теперь оно тоже будет учитываться для следующих элементов.

Таким образом, для каждого элемента мы сначала отвечаем на вопрос «сколько предыдущих не больше него», а затем добавляем его самого в структуру подсчёта.

## Как работает подсчёт

Пусть мы обработали несколько элементов. Массив `counts` хранит частоты значений среди них.

Например, после обработки `[3, 1, 4]`:

- `counts[1] = 1`
- `counts[3] = 1`
- `counts[4] = 1`
- остальные нули.

Если следующий элемент равен `3`, то:

- `sum = counts[1] + counts[2] + counts[3] = 1 + 0 + 1 = 2`.
- Это значит, что среди предыдущих элементов два не превосходят `3`: это `1` и `3`.

После вывода мы увеличиваем `counts[3]` до 2.

---

## Пример работы

Пусть входные данные:

```text
5
3 1 4 2 3
```

Изначально `counts` полностью нулевой.

| i | arr1[i] | sum (counts[1..arr1[i]]) | Вывод | counts после |
|---|---------|--------------------------|-------|--------------|
| 0 | 3       | counts[1]+counts[2]+counts[3] = 0 | 0 | counts[3]=1 |
| 1 | 1       | counts[1] = 0 | 0 | counts[1]=1 |
| 2 | 4       | counts[1]+counts[2]+counts[3]+counts[4] = 1+0+1+0=2 | 2 | counts[4]=1 |
| 3 | 2       | counts[1]+counts[2] = 1+0=1 | 1 | counts[2]=1 |
| 4 | 3       | counts[1]+counts[2]+counts[3] = 1+1+1=3 | 3 | counts[3]=2 |

Вывод программы:

```text
0 0 2 1 3
```

Проверка вручную:

- Для `3`: предыдущих нет → 0.
- Для `1`: предыдущие `[3]`, ни один не `<= 1` → 0.
- Для `4`: предыдущие `[3, 1]`, оба `<= 4` → 2.
- Для `2`: предыдущие `[3, 1, 4]`, только `1 <= 2` → 1.
- Для `3`: предыдущие `[3, 1, 4, 2]`, подходят `3, 1, 2` → 3.

Всё верно.

## Сложность и свойства алгоритма

### Временная сложность

Внешний цикл выполняется `N` раз. Внутренний цикл для элемента `x` выполняется `x` раз. Если максимальное значение равно `M` (в данной программе `M = 100`), то общая сложность:

\[
O(N \cdot M)
\]

Так как `M` — константа (100), фактически это **O(N)**. Но если бы значения могли быть большими (например, до \(10^9\)), сложность стала бы огромной.

### Память

- Массив `counts` — `O(M)` = `O(100)` = `O(1)`.
- Массив `arr1` — `O(N)`.
- Дополнительная память не используется.

### Особенности

- Программа **не сортирует** массив, несмотря на название `CountingSort`.
- Предполагается, что все входные числа лежат в диапазоне `[1, 100]`.
  - Если число больше 100, будет выход за границы массива `counts` — неопределённое поведение.
  - Если число меньше 1 (например, 0 или отрицательное), то внутренний цикл не выполнится, но `counts[arr1[i]]` может обратиться по отрицательному или нулевому индексу, что тоже ошибка.
- `rand()` не используется, программа детерминирована.

## Вопросы на защите

### 1. Что делает программа?

Для каждого элемента массива выводит количество предыдущих элементов, которые не превосходят его по значению.

### 2. Почему функция называется `CountingSort`, хотя она не сортирует?

Это неудачное название. Функция использует идею подсчёта частот (counting), но не выполняет сортировку. Она лишь подсчитывает количество уже встреченных чисел, не больших текущего.

### 3. Что хранится в массиве `counts`?

`counts[x]` — сколько раз значение `x` уже встретилось среди обработанных элементов.

### 4. Почему массив `counts` имеет размер 101?

Потому что предполагается, что все числа находятся в диапазоне от 1 до 100. Индекс 0 не используется, но массив всё равно имеет 101 элемент.

### 5. Что произойдёт, если ввести число больше 100?

Будет выход за границы массива `counts` (индекс > 100). Это неопределённое поведение, программа может упасть или выдать мусор.

### 6. Что произойдёт, если ввести число 0 или отрицательное?

Внутренний цикл `for (int j = 1; j <= arr1[i]; j++)` не выполнится, `sum` останется 0. Затем `counts[arr1[i]]` обратится по индексу 0 или отрицательному, что тоже ошибка (для отрицательного — точно выход за границы).

### 7. Какова сложность алгоритма?

`O(N * M)`, где `M` — максимальное возможное значение (здесь 100). Так как `M` константа, сложность `O(N)`.

### 8. Можно ли ускорить программу?

Да, если хранить префиксные суммы. Но при `M = 100` это не нужно. Если `M` большое, то нужно использовать дерево Фенвика или сортировку с подсчётом инверсий.

### 9. Что нестандартного в коде?

- `int arr1[N];` — VLA, не стандарт C++.
- `std:: cin` с пробелом — допустимо, но выглядит необычно.
- `#include <vector>` подключён, но не используется.

### 10. Как изменить программу, чтобы она действительно сортировала массив?

Нужно после подсчёта частот вывести числа в порядке возрастания: для каждого `x` от 1 до 100 вывести `x` столько раз, сколько `counts[x]`. Но текущая реализация этого не делает.

## Краткое резюме

«Программа читает `N` чисел, предполагая, что каждое из них лежит в диапазоне от 1 до 100. Затем для каждого элемента в исходном порядке выводит, сколько предыдущих элементов не превосходят его по значению. Для этого используется массив частот `counts`: перед обработкой текущего элемента суммируются частоты всех значений от 1 до текущего, что даёт количество предыдущих чисел `<=` текущего. После вывода счётчик текущего значения увеличивается. Сложность `O(N * 100)` = `O(N)`, память `O(N)` для массива и `O(100)` для счётчиков. В коде используются VLA и предполагается, что значения не выходят за пределы 1…100».
