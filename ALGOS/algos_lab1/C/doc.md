## Что делает программа

Программа:

1. Считывает число `N`.
2. Считывает `N` пар чисел. Для каждой пары создаёт строку из трёх чисел:
   - `tracks[i][0]` — первое число пары;
   - `tracks[i][1]` — второе число пары;
   - `tracks[i][2] = i + 1` — исходный номер этой пары (нумерация с 1).
3. Сортирует все строки по возрастанию:
   - сначала по `tracks[i][0]`;
   - если первые числа равны — по `tracks[i][1]`.
4. Выводит только третьи столбцы `tracks[i][2]`, то есть исходные номера пар в порядке после сортировки.

Иначе говоря, программа берёт пары, сортирует их по двум ключам и печатает, в каком порядке эти пары стояли изначально.

Для сортировки используется **сортировка слиянием** `MergeSort`. Это устойчивая сортировка: если две пары полностью равны по первым двум числам, то в результате они сохранят свой исходный относительный порядок.

## Исходный код

```cpp
#include <iostream>

bool Compare(int list1[3], int list2[3]){
    if (list1[0] == list2[0]){
        return (list1[1] <= list2[1]);
    } else{
        return (list1[0] <= list2[0]);
    }
}

void Merge(int list[][3], int left, int mid, int right){
    int i = 0;
    int j = 0;
    int result[right - left][3];

    while ((left + i < mid) && (mid + j < right)){
        if (Compare(list[left + i], list[mid + j])){
            result[i+j][0] = list[left + i][0];
            result[i+j][1] = list[left + i][1];
            result[i + j][2] = list[left + i][2];
            i++;
        } else {
            result[i + j][0] = list[mid + j][0];
            result[i + j][1] = list[mid + j][1];
            result[i + j][2] = list[mid + j][2];
            j++;
        }
    }
    while (left + i < mid){
        result[i + j][0] = list[left + i][0];
        result[i + j][1] = list[left + i][1];
        result[i + j][2] = list[left + i][2];
        i++;
    }
    while (mid + j < right){
        result[i + j][0] = list[mid + j][0];
        result[i + j][1] = list[mid + j][1];
        result[i + j][2] = list[mid + j][2];
        j++;
    }
    for (int p = 0; p < i + j; p++){
        list[left + p][0] = result[p][0];
        list[left +p][1] = result[p][1];
        list[left +p][2] = result[p][2];
    }
}

void MergeSort(int list[][3], int left, int right){
    if (left + 1 >= right){
        return;
    }
    int mid = (left + right)/2;
    MergeSort(list, left, mid);
    MergeSort(list, mid, right);
    Merge(list, left, mid, right);
}

int main(){
    int N;
    std::cin >> N;

    int tracks[N][3];
    for (int i = 0; i < N; i++){
        std::cin >> tracks[i][0] >> tracks[i][1];
        tracks[i][2] = i+1;
    }

    MergeSort(tracks, 0, N);
    for (int i = 0; i < N; i++){
        std::cout << tracks[i][2] << " ";
    }
    return 0;
}
```

## Разбор `main`

```cpp
int main(){
    int N;
    std::cin >> N;

    int tracks[N][3];
    for (int i = 0; i < N; i++){
        std::cin >> tracks[i][0] >> tracks[i][1];
        tracks[i][2] = i+1;
    }

    MergeSort(tracks, 0, N);
    for (int i = 0; i < N; i++){
        std::cout << tracks[i][2] << " ";
    }
    return 0;
}
```

Что происходит:

- `std::cin >> N;` — читаем количество строк.
- `int tracks[N][3];` — создаём двумерный массив: `N` строк, в каждой по 3 числа.
  - **Важно:** это VLA — variable length array. В стандартном C++ размер массива должен быть известен на этапе компиляции. Здесь `N` известен только во время выполнения. GCC и Clang часто это разрешают как расширение. На защите можно сказать: «В стандартном C++ лучше было бы использовать `std::vector<std::array<int, 3>>`, но здесь компилятор GCC допускает VLA».
- Цикл `for`:
  - читает два числа в `tracks[i][0]` и `tracks[i][1]`;
  - записывает в `tracks[i][2]` номер `i + 1`. Это исходный номер пары, чтобы после сортировки мы могли понять, какая пара куда переехала.
- `MergeSort(tracks, 0, N);` — запускаем сортировку.
  - Обратите внимание: передаётся `N`, а не `N - 1`.
  - Значит, сортировка работает с полуинтервалом `[left, right)`: левая граница включается, правая — нет.
  - То есть `MergeSort(tracks, 0, N)` сортирует элементы с индексами `0, 1, ..., N-1`.
- Последний цикл выводит `tracks[i][2]` — исходные номера пар в отсортированном порядке.

Почему передаётся `tracks`, а не `tracks[N][3]`?  
Потому что имя двумерного массива при передаче в функцию превращается в указатель на первую строку. Функция получает доступ к оригинальному массиву и может его менять.

## Функция `Compare`

```cpp
bool Compare(int list1[3], int list2[3]){
    if (list1[0] == list2[0]){
        return (list1[1] <= list2[1]);
    } else{
        return (list1[0] <= list2[0]);
    }
}
```

Функция сравнивает две строки по трём числам, но реально использует только первые два.

Логика:

- Если первые числа равны (`list1[0] == list2[0]`), сравниваем вторые числа:
  - возвращаем `true`, если `list1[1] <= list2[1]`;
  - иначе `false`.
- Если первые числа не равны, сравниваем первые:
  - возвращаем `true`, если `list1[0] <= list2[0]`;
  - иначе `false`.

Что означает `true`?  
В этой программе `Compare(a, b) == true` означает: «элемент `a` должен идти не позже элемента `b`». То есть `a` считается меньшим или равным `b`.

### Важный нюанс: почему `<=`, а не `<`

Обычно для строгого компаратора используют `<`, чтобы `Compare(x, x)` было `false`. Здесь же при полном равенстве `Compare(x, x)` вернёт `true`.

Для `std::sort` такой компаратор был бы некорректен, потому что он не задаёт строгий слабый порядок. Но в этой программе `Compare` используется только внутри собственной сортировки слиянием. Там это работает как правило:

> Если левый элемент `<=` правого, берём левый.

Это как раз обеспечивает **устойчивость**: при равенстве первым выбирается элемент из левой половины, то есть тот, который стоял раньше в исходном массиве.

## Функция `MergeSort`

```cpp
void MergeSort(int list[][3], int left, int right){
    if (left + 1 >= right){
        return;
    }
    int mid = (left + right)/2;
    MergeSort(list, left, mid);
    MergeSort(list, mid, right);
    Merge(list, left, mid, right);
}
```

Параметры:

- `list[][3]` — сортируемый двумерный массив;
- `left` — левая граница (включается);
- `right` — правая граница (не включается).

То есть функция сортирует часть массива на полуинтервале `[left, right)`.

### База рекурсии

```cpp
if (left + 1 >= right){
    return;
}
```

Если длина отрезка `right - left` меньше или равна 1, то есть `left + 1 >= right`, сортировать нечего. Один элемент или пустой отрезок уже отсортированы.

Примеры:

- `left = 0, right = 1` → длина 1 → выходим.
- `left = 0, right = 0` → длина 0 → выходим.

### Разделение

```cpp
int mid = (left + right)/2;
```

Находим середину. Делим отрезок на две части:

- левая: `[left, mid)`;
- правая: `[mid, right)`.

Например, если `left = 0`, `right = 5`, то `mid = 2`. Левая часть — индексы 0, 1. Правая — 2, 3, 4.

### Рекурсивная сортировка половин

```cpp
MergeSort(list, left, mid);
MergeSort(list, mid, right);
```

Сначала рекурсивно сортируем левую половину, затем правую.

### Слияние

```cpp
Merge(list, left, mid, right);
```

Когда обе половины отсортированы, сливаем их в один отсортированный отрезок.

## Функция `Merge`

```cpp
void Merge(int list[][3], int left, int mid, int right){
    int i = 0;
    int j = 0;
    int result[right - left][3];

    while ((left + i < mid) && (mid + j < right)){
        if (Compare(list[left + i], list[mid + j])){
            result[i+j][0] = list[left + i][0];
            result[i+j][1] = list[left + i][1];
            result[i + j][2] = list[left + i][2];
            i++;
        } else {
            result[i + j][0] = list[mid + j][0];
            result[i + j][1] = list[mid + j][1];
            result[i + j][2] = list[mid + j][2];
            j++;
        }
    }
    while (left + i < mid){
        result[i + j][0] = list[left + i][0];
        result[i + j][1] = list[left + i][1];
        result[i + j][2] = list[left + i][2];
        i++;
    }
    while (mid + j < right){
        result[i + j][0] = list[mid + j][0];
        result[i + j][1] = list[mid + j][1];
        result[i + j][2] = list[mid + j][2];
        j++;
    }
    for (int p = 0; p < i + j; p++){
        list[left + p][0] = result[p][0];
        list[left +p][1] = result[p][1];
        list[left +p][2] = result[p][2];
    }
}
```

Функция сливает два уже отсортированных соседних отрезка:

- левый: `[left, mid)`;
- правый: `[mid, right)`.

В результате весь отрезок `[left, right)` должен стать отсортированным.

### Переменные

```cpp
int i = 0;
int j = 0;
```

- `i` — сколько элементов уже взято из левой половины.
- `j` — сколько элементов уже взято из правой половины.

Текущий элемент левой половины: `list[left + i]`.  
Текущий элемент правой половины: `list[mid + j]`.

### Временный массив `result`

```cpp
int result[right - left][3];
```

Создаётся временный массив на `right - left` строк. В него будет складываться результат слияния.

Это тоже VLA, потому что `right - left` известен только во время выполнения. В стандартном C++ лучше использовать `std::vector`.

### Основной цикл слияния

```cpp
while ((left + i < mid) && (mid + j < right)){
    if (Compare(list[left + i], list[mid + j])){
        // берём элемент из левой половины
        ...
        i++;
    } else {
        // берём элемент из правой половины
        ...
        j++;
    }
}
```

Пока в обеих половинах есть элементы, сравниваем текущие элементы через `Compare`.

- Если `Compare(левый, правый) == true`, значит левый должен идти раньше или они равны. Берём левый, увеличиваем `i`.
- Иначе берём правый, увеличиваем `j`.

Каждый взятый элемент копируется в `result[i + j]` по всем трём столбцам.

Почему `i + j`?  
Потому что `i` элементов уже взято слева, `j` — справа. Значит, всего уже взято `i + j` элементов. Это индекс следующей свободной позиции в `result`.

### Дописывание остатков

```cpp
while (left + i < mid){
    // копируем оставшиеся элементы левой половины
    i++;
}
while (mid + j < right){
    // копируем оставшиеся элементы правой половины
    j++;
}
```

Если одна половина закончилась, а в другой ещё остались элементы, просто копируем их в конец `result`. Они уже отсортированы, поэтому ничего сравнивать не нужно.

### Копирование обратно

```cpp
for (int p = 0; p < i + j; p++){
    list[left + p][0] = result[p][0];
    list[left +p][1] = result[p][1];
    list[left +p][2] = result[p][2];
}
```

После слияния в `result` лежит отсортированный отрезок длины `i + j`. Копируем его обратно в исходный массив `list`, начиная с позиции `left`.

К концу функции `i + j` должно быть равно `right - left`, то есть длине отрезка.

## Пример работы

Пусть входные данные:

```text
3
2 1
1 5
1 2
```

Тогда в `main` получится:

```cpp
tracks[0] = {2, 1, 1}
tracks[1] = {1, 5, 2}
tracks[2] = {1, 2, 3}
```

Вызывается `MergeSort(tracks, 0, 3)`.

### Шаг 1. `MergeSort(0, 3)`

`left = 0`, `right = 3`, `mid = 1`.

Рекурсивно сортируем:

- `MergeSort(0, 1)` — отрезок из одного элемента, ничего не делает.
- `MergeSort(1, 3)` — сортируем элементы с индексами 1 и 2.

### Шаг 2. `MergeSort(1, 3)`

`left = 1`, `right = 3`, `mid = 2`.

Рекурсивно:

- `MergeSort(1, 2)` — один элемент, ничего.
- `MergeSort(2, 3)` — один элемент, ничего.

Затем `Merge(list, 1, 2, 3)`.

Левая половина: `[1, 2)` — это `tracks[1] = {1, 5, 2}`.  
Правая половина: `[2, 3)` — это `tracks[2] = {1, 2, 3}`.

Сравниваем `{1, 5, 2}` и `{1, 2, 3}`:

- первые числа равны: `1 == 1`;
- сравниваем вторые: `5 <= 2`? Нет.
- значит, берём правый элемент `{1, 2, 3}`.

Копируем его в `result[0]`. `j = 1`.

Правая половина закончилась. Дописываем левую: `{1, 5, 2}` в `result[1]`.

Копируем обратно. Теперь:

```cpp
tracks[1] = {1, 2, 3}
tracks[2] = {1, 5, 2}
```

### Шаг 3. `Merge(list, 0, 1, 3)`

Теперь сливаем:

- левая половина: `[0, 1)` — `tracks[0] = {2, 1, 1}`;
- правая половина: `[1, 3)` — `{1, 2, 3}`, `{1, 5, 2}`.

Сравниваем `{2, 1, 1}` и `{1, 2, 3}`:

- первые числа: `2 <= 1`? Нет.
- берём правый `{1, 2, 3}`.

Сравниваем `{2, 1, 1}` и `{1, 5, 2}`:

- `2 <= 1`? Нет.
- берём правый `{1, 5, 2}`.

Правая половина закончилась. Дописываем левую `{2, 1, 1}`.

Итоговый массив:

```cpp
tracks[0] = {1, 2, 3}
tracks[1] = {1, 5, 2}
tracks[2] = {2, 1, 1}
```

Выводим третьи столбцы:

```text
3 2 1
```

Что логично: пары `(1,2)`, `(1,5)`, `(2,1)` в исходном порядке имели номера 3, 2, 1.

## Сложность и свойства алгоритма

### Временная сложность

Сортировка слиянием всегда делит массив примерно пополам. Глубина рекурсии — `O(log n)`. На каждом уровне выполняется `O(n)` работы по слиянию.

Итого: **O(n log n)** в лучшем, среднем и худшем случае.

### Память

Дополнительно используется временный массив `result` на каждом слиянии. В любой момент активен только один `Merge`, поэтому дополнительная память — **O(n)**.

Также есть стек рекурсии глубиной **O(log n)**.

### Устойчивость

Сортировка **устойчивая**. Если две строки равны по первым двум числам, то при слиянии левая половина берётся раньше правой, потому что `Compare` возвращает `true` при равенстве. Значит, исходный порядок таких строк сохраняется.

Именно поэтому в третьем столбце хранится исходный номер: после сортировки можно увидеть, что равные элементы не поменялись местами.

## Вопросы на защите

### 1. Что делает программа?

Сортирует пары чисел по первому, затем по второму числу, и выводит исходные номера этих пар в отсортированном порядке.

### 2. Почему в `tracks[i][2]` записывается `i + 1`?

Чтобы запомнить исходный номер пары. После сортировки строки переставляются, а третье число остаётся привязанным к своей паре. По нему мы понимаем, какая пара где была изначально.

### 3. Как работает `Compare`?

Сравнивает два элемента. Если первые числа равны, сравнивает вторые. Иначе сравнивает первые. Возвращает `true`, если первый элемент должен идти раньше или равен второму.

### 4. Почему в `Compare` используется `<=`, а не `<`?

Чтобы при равенстве выбирать левый элемент. Это делает сортировку устойчивой. Для `std::sort` такой компаратор был бы некорректен, но здесь своя реализация слияния, и это работает.

### 5. Что такое `MergeSort`?

Это рекурсивная сортировка слиянием. Она делит отрезок пополам, рекурсивно сортирует каждую половину, а затем сливает их в один отсортированный отрезок.

### 6. Что означают `left`, `mid`, `right`?

- `left` — начало отрезка (включается);
- `right` — конец отрезка (не включается);
- `mid` — середина, начало правой половины.

Левая половина: `[left, mid)`.  
Правая половина: `[mid, right)`.

### 7. Почему база рекурсии `left + 1 >= right`?

Потому что если длина отрезка `right - left` меньше или равна 1, то есть `left + 1 >= right`, сортировать нечего. Один элемент или пустой отрезок уже отсортированы.

### 8. Как работает `Merge`?

Он сливает две уже отсортированные половины. Идёт двумя указателями `i` и `j` по левой и правой половинам. Сравнивает текущие элементы и берёт меньший. Когда одна половина заканчивается, дописывает остатки другой. Результат складывает во временный массив `result`, потом копирует обратно в `list`.

### 9. Почему `result` имеет размер `right - left`?

Потому что сливаемый отрезок `[left, right)` содержит ровно `right - left` элементов. Значит, временный массив должен вмещать столько же строк.

### 10. Почему после слияния `i + j == right - left`?

Потому что каждый элемент из левой и правой половин должен быть взят ровно один раз. Всего элементов `right - left`. Значит, сумма взятых слева и справа равна длине отрезка.

### 11. Что если `N = 0`?

`MergeSort(tracks, 0, 0)` сразу вернётся, потому что `left + 1 >= right` — это `1 >= 0`, истина. Цикл вывода не выполнится ни разу. Программа ничего не выведет.

### 12. Что если `N = 1`?

`MergeSort(tracks, 0, 1)` вернётся, потому что `1 >= 1`. Выведется `tracks[0][2]`, то есть `1`.

### 13. Что нестандартного в коде?

Два момента:

- `int tracks[N][3];` — VLA.
- `int result[right - left][3];` — тоже VLA.

В стандартном C++ размер массива должен быть константой времени компиляции. Здесь используются расширения компилятора. Альтернатива — `std::vector<std::array<int, 3>>`.

### 14. В чём отличие от QuickSort?

QuickSort в среднем быстрее и сортирует на месте, но в худшем случае даёт `O(n²)` и не устойчив. MergeSort всегда `O(n log n)`, устойчив, но требует `O(n)` дополнительной памяти.

### 15. Почему выводится только `tracks[i][2]`?

Потому что по условию нужно вывести исходные номера пар в порядке после сортировки. Сами числа пар уже не нужны.

## Краткое резюме

«Программа читает `N` пар чисел. Для каждой пары запоминает её исходный номер в третьем столбце. Затем сортирует пары с помощью сортировки слиянием: сначала по первому числу, при равенстве — по второму. Сортировка слиянием рекурсивно делит массив пополам, сортирует половины и сливает их. При слиянии сравнивает элементы через `Compare` и при равенстве берёт левый, поэтому сортировка устойчивая. После сортировки выводит третьи столбцы — исходные номера пар. Временная сложность `O(n log n)`, дополнительная память `O(n)`. В коде используются VLA, что не является стандартом C++, но компилятор GCC это допускает».
